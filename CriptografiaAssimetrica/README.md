# Criptografia Assimétrica RSA

A aplicação em C# demonstra a criptografia assimétrica utilizando o algoritmo RSA.

## Funcionalidades

- Gerar chaves pública e privada.
- Criptografar mensagens com a chave pública.
- Descriptografar mensagens com a chave privada.
- Testar uma chave privada incorreta.

## Como executar

É necessário ter o SDK do .NET 8 ou compatível instalado.

No terminal, dentro da pasta do projeto, execute:

```bash
dotnet run
```

## Tecnologias

- C#
- .NET
- RSA
- OAEP com SHA-256
